# Changelog

All notable public changes are documented in this file.

## 1.0.0 — 2026-08-06

- Initial publication-ready release under the scientific repository name `spei-3d-drought-object-tracking`.
- Added deterministic maximum-overlap, overlap-union, and maximum-IoU temporal-linking rules.
- Added one-factor-at-a-time sensitivity workflows for accumulation scale, drought threshold, monthly patch area, duration, peak area, and linking rule.
- Added strict validation of monthly time continuity and regular latitude–longitude coordinates.
- Added portable YAML configurations, synthetic tests, release auditing, optional Zarr label output, and reproducibility metadata.
- Added complete method mapping, output schema, release checklist, and GitHub upload instructions.
